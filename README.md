# Tennis Swing Classification
This README is to help you get this project up and running locally. 
All helper classes are stored in classes/ and all code for generating the pose and image data is stored in the jupyter notebooks

## Running Model files
After creating a local proiject structure the same as above if you run the processing.ipynb notebook it will split all videos into frames and generate all pose data both original as well as merged with its corresponding horizontal flip. After this you should be able to run all of the Model files from start to finish. I may have left out a create_folder() somewhere but from locla testing it all seems to be generating ok!

## Model results comparison
I then collated all of the data into the Results_Comparison.ipynb notebook to genereate the graphs at the bottom of the report. I converted the classification report into a dict by hand for the original CNN and then copied the dict structure and replaced values for each new model as they were created. If i have time Ill write a function to build this automatically for you but again time depenedent...
